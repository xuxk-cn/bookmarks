# cf-nav 导航站 · 部署说明

> 任何人按本说明操作，5 分钟即可在自己的 Cloudflare 账户上拥有一个专属书签导航站。
> 数据（书签/密码/设置）全部存在你自己的 Cloudflare KV 里，与他人完全隔离。

---

## 一、准备（一次性）

| 需要 | 获取方式 |
|------|---------|
| Cloudflare 账号 | https://dash.cloudflare.com/sign-up 免费注册 |
| **Global API Key** | Dashboard 右上角头像 → **My Profile** → **API Tokens** → 页面下方 **Global API Key → View** |
| 部署器安装包 | `cf-nav-deployer.zip`（获取方式见文末） |
| 书签文件（可选） | Chrome/Edge：书签管理器 → 导出书签 → 得到 `bookmarks_x_x_x.html` |

---

## 二、部署步骤（共 2 步）

### 第 1 步：安装部署器

1. 登录 Cloudflare Dashboard → 左侧 **Workers & Pages**
2. **Create application** → **Pages** → **Upload assets**
3. 项目名随意（例如 `my-nav-deployer`）→ 上传 `cf-nav-deployer.zip` → **Deploy**
4. 部署完成后点 **Visit site** 打开部署器页面

> ✅ 自检：页面标题「cf-nav 部署器」下方有一行**红色版本号**（如 `v20260825-76`）。看到它说明页面是最新版；看不到就按 **Ctrl+F5** 强制刷新。

### 第 2 步：一键部署导航站

在部署器页面依次填写：

| 栏目 | 填什么 |
|------|--------|
| ① Cloudflare 凭据 | 你的注册邮箱 + Global API Key → 点「验证并加载账户」 |
| ② Pages 项目名 / KV 名 | 保持随机生成的即可（也可自定义） |
| ② 站点名称 | 你的导航站名字 |
| ② 管理员用户名/密码 | **记牢**，这是后台登录凭据 |
| ② 自定义域名 | 可留空（默认送 `xxx.pages.dev` 域名） |
| ③ 导入书签 | 点「选择文件」选你的书签 HTML（可跳过，之后后台也能导） |

点击 **一键部署**，等待 1~3 分钟，日志依次出现：

```
[1/3] 准备环境...        ← 自动创建 KV、写入书签、创建 Pages 项目
[2/3] 上传 76 个静态文件  ← 按 commit SHA 从 GitHub 拉取最新代码（无缓存问题）
[3/3] 提交部署... ✅ 部署完成！
```

日志会给出：
```
项目名:   nav-xxxxxxxx
访问地址: https://nav-xxxxxxxx.pages.dev
管理后台: https://nav-xxxxxxxx.pages.dev/admin
```

## 三、部署完成后：后台功能速览

用管理员账号登录 `/admin`，左侧 6 个页面：

| 页面 | 用途 |
|------|------|
| 📚 书签管理 | 增删改排序；工具栏 6 个按钮：<br>🖼**抓取图标**（选中）/ 📝**抓取悬停**（选中）/ 🖼**批量抓取全部** / 📝**批量抓取悬停** / 🤖AI补选中 / 全选 |
| 📂 分类管理 | 分类增删改排序 |
| 🤖 AI 补描述 | 选 Provider（CF Workers AI 免费 / Gemini / OpenAI）批量生成介绍 |
| 📥 投稿审核 | 开放投稿后审核用户提交 |
| 📤 导入导出 | 随时导入/备份书签（JSON / HTML） |
| ⚙️ 站点设置 | 站名/默认风格/背景/**站点美化**（主题、毛玻璃、3D 倾斜、天气联动等）/ 改密码 |

**推荐新站三连**：① 🖼批量抓取全部 → ② 📝批量抓取悬停 → ③ ⚙️站点设置里挑喜欢的背景和美化项。

## 四、常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 部署器页面**没有红色版本号** | 打开的是旧页面/旧地址。关掉标签，从 Dashboard 该项目 **Deployments → Production** 的域名重新进入，或 Ctrl+F5 |
| 日志显示「上传 101 个文件」 | 同上，前端是旧版。以红色版本号为准 |
| 「获取 GitHub commit SHA 失败: 403」 | GitHub 匿名限流，部署器已内置 git 协议兜底，**点重试**即可 |
| 部分网站悬停介绍没抓到 | 该站无 meta 描述或反爬。用「🤖AI补选中」生成 |
| 想换/更新导航站代码 | 重新上传新版 zip 到**同一个部署器项目**（Create deployment），再一键部署一次；**书签数据不受影响**（存在 KV 里） |
| 忘记管理员密码 | Dashboard → KV → 找到对应 `nav-kv-*` → 删除 `admin_password` 键 → 重新一键部署时设置新密码 |

---

## 五、数据与安全

- 部署器**不保存**你的邮箱/API Key（仅本次部署临时使用）
- 书签、设置、密码存放在**你自己账户**的 KV 命名空间中
- 想迁移：后台「导出 JSON」→ 在新站「导入」即可
